# Git boundary (ADR-002)

The pipeline produces files in two places: the app repo (capture home) and the
`app-store-screenshots/` scaffold (beautify home). The rule is simple:

> Git tracks intent and creative work (json, config, source). Git never tracks generated
> pixels (PNG) or build output.

## App repository root

```gitignore
# fastlane — screenshots are regenerable; re-run fastlane to recreate them
fastlane/report.xml
fastlane/Preview.html
fastlane/screenshots/**/*.png
fastlane/test_output

# App Store Connect metadata is reproducible from export
fastlane/metadata/screenshots/

# Secrets
.env
*.p8
AuthKey_*.p8
```

`fastlane/screenshots/**/*.png` is ignored on purpose: it is a deterministic build product
(fastlane `raw_screenshots`). This follows the community Swift.gitignore and fastlane's own
best-practice guidance. Cross-machine beautify is done by copying that folder or
re-running capture on a Mac — not by committing binaries.

Track in the app repo: `fastlane/Fastfile`, `fastlane/Snapfile`, `fastlane/Appfile`,
`Gemfile`/`Gemfile.lock`, the UI test target, `DemoDataBuilder`, and the generated
`listing.json`.

## Scaffold: app-store-screenshots/

```gitignore
# engine source is regenerated by the skill; never edit by hand in a tracked way
/src
/style-prompts

# derived and build output
/public/screenshots
/node_modules
/.next
/exports

# secrets
.env
*.p8
```

Track in the scaffold: `app-store-screenshots.json` (the user's copy, layout, theme —
the irreplaceable creative work), plus `bun.lock`, `package.json`, `next.config.*`,
`tsconfig.json`, `components.json`, and the public bezel/mockup assets.

## Why

- **No binary bloat.** Screenshots and builds stay out of history.
- **No drift.** `public/screenshots/` is a derived copy of `fastlane/screenshots/`; only
  the latter is the source of truth.
- **Portable creative work.** The user's tuned `app-store-screenshots.json` travels with
  the repo and resumes on any machine after a one-time `bun install`.
- **No leaked credentials.** `.env` / `*.p8` are never committed; ship `.env.example` with
  placeholder keys instead.
